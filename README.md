# Urrao Avocado Resilience Partnership

A bilingual English/Spanish prototype exploring how small and medium avocado farmers in Urrao could report extreme-weather damage, verify impacts, access recovery support, and track progress.

## Live website

https://hophihaonguyen2-ui.github.io/urrao-avocado-resilience/

This is a demonstration prototype. All farmer details, financial figures, programme rules, and contract terms are illustrative.
